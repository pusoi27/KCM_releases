Guided setup for two-station architecture: Scanner as API client, Instructor as API server, and snapshots from instructor only.

Recommended architecture (v01.03.00+)
Use a single source of truth DB on Instructor Station. Scanner Station talks to Instructor via local network API.
  1. Instructor Station: set mode to Instructor API Server.
  2. Scanner Station: set mode to Scanner API Client and pair using Instructor URL + token.
  3. Use Instructor snapshots-only backup mode to avoid OneDrive split-brain conflicts.
